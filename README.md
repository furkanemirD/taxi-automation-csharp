# Taksi_güncel

C# ve Windows Forms (.NET) ile geliştirilmiş bir taksi otomasyon uygulamasıdır (`Taksi_güncel.sln`). `Form1.cs`, `FrmAnaForm.cs` ve `Veritabanı.cs` dosyalarından, bir giriş/ana ekran akışı ile veritabanı bağlantısı içeren bir masaüstü yönetim uygulaması olduğu anlaşılmaktadır.

## Klasör Yapısı

- `Taksi_güncel/` — Uygulamanın kaynak kodları (Form dosyaları, `Program.cs`, `Veritabanı.cs`, `Properties/`)
- `Taksi_güncel.sln` — Visual Studio çözüm dosyası
